# Easy Tools（PyQt6）

## 概览
这是一个桌面工具集合应用，当前已实现：
- PDF 转长图

## 界面结构
- 左侧：工具导航（可伸缩）
- 右侧：当前工具页面
- 选择工具后，导航会自动收缩，预留更多内容显示空间

## PDF 转长图（已轻量化）
### 交互结构
- 左侧控制区：基础设置 + 可折叠高级选项
- 右侧预览区：大面积预览（更适合高>宽的 PDF）

### 预览能力
- 上一页/下一页/页码跳转
- 显示模式：`适应宽度`、`适应页面`、百分比缩放
- 在窗口大小变化时，适应模式会自动重算并刷新显示

### 导出能力
- 导出 PNG/JPG
- 支持页码范围语法：`9-11`、`1,3,9-11`
- 导出过程显示进度，完成后可直接打开文件/目录

## 环境
- Python 3.10+

## 安装依赖
```bash
pip install -r requirements.txt
```

## 运行
```bash
python main.py
```
